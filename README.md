# QueerSafe

**LGBTQ+ safety and meeting planning.** A lightweight, mobile-friendly web prototype.

## Prototype features
- Prepare a meeting plan and generate a message to send to a trusted contact.
- Prepare a check-in message.
- Review general safety tips and emergency guidance.
- Responsive interface and basic installable/offline web-app support.

## Important limitations
- This is a prototype, not an emergency response service.
- It does not connect to Grindr or any other dating service.
- It does not send alerts automatically, track GPS/live location, or contact trusted people or emergency services.
- Meeting details are assembled in the browser and are not sent to a QueerSafe server by this static site.
- Any sample places are illustrative only, not verified recommendations.
- Do not use it to publish accusations or personal data about other people.

## Run locally
Serve this folder over HTTP (for example with GitHub Pages). The service worker requires HTTPS or localhost.
